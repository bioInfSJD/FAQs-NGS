# FAQs-NGS

## Passos per publicar i compartir la pàgina

1. **Activa GitHub Pages:** Settings → Pages → *Deploy from a branch* → Branch **main** / **/ (root)** → Save.
2. **Copia l'URL:** `https://bioinfsjd.github.io/FAQs-NGS/faqs.html`
3. **Genera el QR:** enganxa l'URL en un generador de QR (p. ex. qrcode-monkey.com) i descarrega'l.

## Actualitzar el llistat de panells

1. Descarrega la carpeta **Panells** del SharePoint i comprimeix-la en un **.zip**.
2. Reemplaça el **Panells.zip** del repositori pel nou (Add file → Upload files → Commit).
3. El workflow regenera `faqs.html` automàticament.
